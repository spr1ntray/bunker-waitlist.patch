# BUNKER

Soft Hub patch for [thebunkerhood.com](https://thebunkerhood.com).

## Install

```text
dist/bunker-waitlist-1.2.9.softhub.zip
```

Soft Hub → Patches → drop the zip → Prepare if needed.

## Actions

| Action | What it does |
|---|---|
| Register | Join waitlist via account proxy |
| Mint | Wait for allowlist and mint WL. Does not list or sell |

## Build

```bash
python3 scripts/build_plugin.py \
  bunker-waitlist \
  dist/bunker-waitlist-1.2.9.softhub.zip
```
